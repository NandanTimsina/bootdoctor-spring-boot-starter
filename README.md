# BootDoctor

[![CI](https://github.com/NandanTimsina/bootdoctor-spring-boot-starter/actions/workflows/ci.yml/badge.svg)](https://github.com/NandanTimsina/bootdoctor-spring-boot-starter/actions/workflows/ci.yml)

**When your Spring Boot app fails to start, get a short plain-English diagnosis instead of a 100-line stack trace.**

BootDoctor is a Spring Boot starter. Add one dependency, and if your app crashes on startup it prints the likely cause, a suggested fix, how confident it is, and the exact lines of the error it based that on. Secrets are masked before anything leaves your machine, and if anything goes wrong inside BootDoctor, your app's own error is still printed as usual.

## Why I built it

Every Spring Boot beginner (including me) has stared at a wall of stack trace where the one useful line is buried near the bottom, under `Caused by:` three levels deep. Spring has built-in explanations for some failures, but not all. A refused database connection or a missing `${PLACEHOLDER}` still gives you the raw trace. BootDoctor fills that gap.

## What it looks like

My app was missing an environment variable. Spring printed a stack trace of 100+ lines. With BootDoctor added, this appears right before it:

```
BootDoctor: asking openai/gpt-oss-20b to explain this failure (waiting up to 8.0 s)...

======================================================================
 BootDoctor diagnosis
======================================================================
Likely cause : Missing JWT_SECRET property causing bean creation
               failure
Suggested fix: Add JWT_SECRET to application.properties or set as
               environment variable, e.g., JWT_SECRET=yourSecretKey
Confidence   : high
Evidence:
  - org.springframework.util.PlaceholderResolutionException: Could not
    resolve placeholder 'JWT_SECRET'
  - org.springframework.beans.factory.UnsatisfiedDependencyException:
    Error creating bean with name 'authTokenFilter': Unsatisfied
    dependency expressed through field 'jwtService'

AI-generated by openai/gpt-oss-20b in 2.2 s. It can be wrong, check before acting.
======================================================================
```

Same idea for a stopped database: it reports that the app cannot reach PostgreSQL at `localhost:5432` and that the database must be running, quoting the real error lines as evidence.
